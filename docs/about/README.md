# 关于本站

**Glyceryl's Developer Hub** 是个人开发笔记站，长期记录 Minecraft、Java、Unity、C# 和开发工具相关知识。

旧站中针对 Minecraft 1.19.2 / Forge 43.2.0 撰写的教程和图片仍按原文件路径保存。新页面与旧稿并存；旧版内容不默认代表当前 API 或官方最佳实践。

## 阅读与维护方式

- 从[首页](/)按主题进入。
- 使用左侧目录搜索，也可以按 `Ctrl + K` / `⌘ + K` 聚焦搜索框。
- 顶部按钮可切换明暗主题，偏好仅保存在本机浏览器。
- 发现笔误或失效链接，可在[网站仓库](https://github.com/Glyceryl6/glyceryl6.github.io)提出 Issue / PR。
- 不提供游戏私有源码、绕过反作弊手段或未经许可的游戏文件。

有关公开范围及账号处罚风险，请阅读[内容发布原则](about/publication-policy.md)和[游戏第三方工具声明](unity/safety.md)。
