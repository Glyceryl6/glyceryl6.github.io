## 官方规则与处罚风险

《吉星派对》官方于 **2026 年 5 月 28 日**发布的公告说明，已对核实使用非法脚本的违规账号进行永久封禁处理，并披露当次处罚超过 5000 个账号。官方的公平运营声明还对外挂、第三方工具及解析、传播游戏素材提出限制。

- [官方微博公告（转引官方发布内容）](https://www.sina.cn/news/detail/5303593969910109.html)
- [游戏公告汇总（含非法脚本处罚）](https://wiki.biligame.com/starengine/游戏内公告)
- [游戏公平运营声明](https://wiki.biligame.com/starengine/官方公告/151)

**不应把“仅自己使用”“私下使用”“没有破坏平衡”理解为官方许可。** 未经许可的第三方插件可能导致账号限制、永久封禁、游戏故障或其他后果；游戏规则与执法方式也可能变化。下载、修改或使用相关软件前，应独立核对最新官方服务条款与公告，并自行承担风险。


## 本站公开什么，不公开什么

**可以公开：** 合法可分发的 Java / C# 开发教程、官方或开源工具链接、SDK 的通用 API 概念、独立测试工程、常见的 MSBuild 与 NuGet 排错方法。

**不公开：** 尚未公开的 AstralProbe 功能实现（作者计划逐步开源，已公开部分除外）、游戏热更新源码文件本身、可直接下载游戏资源或程序集的地址、绕过反作弊或账号保护的指南、可能破坏公平匹配的自动化脚本。

本站的内容旨在帮助理解软件工程知识；不提供针对未获授权目标的运行保证，不保证第三方工具安全或免于处罚。免责声明不豁免任何法律责任或用户协议义务。

如果未来发布公开 MOD 示例，将优先采用自建或经授权的演示环境，并再次审查使用许可与发布范围。
