# Minecraft 历史教程（归档）

这里保留原站的全部 Minecraft 模组教程，**不是 2026 年最新的 Minecraft 或 Forge 通用教程**。旧文章的 API、截图与下载链接可能已经失效，实际开发请以对应版本的官方文档为准。

> 本站的主线内容已经转向 Unity / IL2CPP / HybridCLR。为了让两套教程各自独立，历史教程改由本页单独导航，主站侧边栏不再混排旧文章。
