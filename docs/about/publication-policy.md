# 公开文档与隐私边界

本仓库通过 GitHub Pages 公开发布。**不要把“仓库是私有的”当作“网站内容自动私有”**：一旦被发布到公开站点，网页、截图、URL 和构建产物都应视为公开信息。

## 允许纳入公开站点的内容

- 基于公开资料、合法引用和原创示例整理的开发笔记。
- Minecraft 历史教程及已拥有再发布权的自制截图。
- 开源 SDK 的使用概念与 API 契约（不含受限源代码）。
- 对通用 MSBuild、NuGet、IL2CPP 原理的解释。

## 不应提交或发布的内容

- 私有 AstralProbe 源码、服务端逻辑、非公开游戏热更新源码或其取得方式。
- 未经许可的游戏资源、完整商业游戏程序集或他人私有补丁。
- 反作弊绕过、未获授权的竞技自动化、账号处罚规避指南。
- API 密钥、个人账号、令牌、本机配置、调试日志中的敏感标识。

## PR 和构建审核

本站部署脚本**只复制白名单**：`index.html`、`.nojekyll`、`docs/` 与 `assets/`。即使仓库里有构建脚本或历史 `.git` 元数据，也不会被部署成网页。新增公开文档之前仍应人工审查：白名单不能自动判断文章是否涉及敏感内容。

对于任何第三方游戏，请先确认其服务条款。即便是私人测试，也不保证免于账号处罚。详见[风险说明](unity/safety.md)。
