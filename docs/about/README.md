# 关于本站

**Glyceryl's Developer Hub** 是个人开发笔记站，围绕 Unity / IL2CPP / HybridCLR 的 MOD 开发，记录工程实践、SDK 与工具链经验。

早期针对 Minecraft 1.19.2 / Forge 43.2.0 撰写的教程与图片仍按原文件路径保存在仓库中，但已经过期，站点不再提供入口；它们不代表当前的 API 或最佳实践。

## 阅读与维护方式

- 从[首页](/)按主题进入。
- 顶部搜索框可直接搜索；也可以按 `Ctrl + K` / `⌘ + K` 聚焦。
- 顶部配色按钮提供“跟随系统 / 浅色 / 深色”三档：默认跟随系统，系统主题变化时会自动切换；选择仅保存在本机浏览器，不会上传。
- 分类导航紧跟在 Logo 右侧；窄屏下自动收起，改由左侧目录导航。
- 发现笔误或失效链接，可在[网站仓库](https://github.com/Glyceryl6/glyceryl6.github.io)提出 Issue / PR。
- 不提供游戏私有源码、绕过反作弊手段或未经许可的游戏文件。

有关公开范围及账号处罚风险，请阅读[内容发布原则](about/publication-policy.md)和[游戏第三方工具声明](unity/safety.md)。
