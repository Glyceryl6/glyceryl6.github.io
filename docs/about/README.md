# 关于本站

**Glyceryl's Developer Hub** 是个人开发笔记站，记录 Unity / IL2CPP / HybridCLR 的 MOD 开发经验，以及 C#、工具链与早期 Minecraft 教程。

站点分为两个部分：

- **主站**（当前页）：Unity MOD 开发专题、SDK 与工具文档。
- **历史教程**：Minecraft 1.19.2 / Forge 43.2.0 的旧文章与截图，通过顶部“历史教程”或 <a href="history.html" target="_self">history.html</a> 进入，使用独立导航，可随时返回主站。

旧站中针对 Minecraft 撰写的教程和图片仍按原文件路径保存。旧版内容不默认代表当前 API 或官方最佳实践。

## 阅读与维护方式

- 从[首页](/)按主题进入。
- 使用左侧目录搜索，也可以按 `Ctrl + K` / `⌘ + K` 聚焦搜索框。
- 顶部配色按钮提供“跟随系统 / 浅色 / 深色”三档：默认跟随系统，系统主题变化时会自动切换；选择仅保存在本机浏览器，不会上传。
- 顶部分类导航位于 Logo 右侧；窄屏下自动收起，改由左侧目录导航。
- 顶部“历史教程”进入独立页面，该页有自己的导航栏，右上角可返回主站。
- 发现笔误或失效链接，可在[网站仓库](https://github.com/Glyceryl6/glyceryl6.github.io)提出 Issue / PR。
- 不提供游戏私有源码、绕过反作弊手段或未经许可的游戏文件。

有关公开范围及账号处罚风险，请阅读[内容发布原则](about/publication-policy.md)和[游戏第三方工具声明](unity/safety.md)。
